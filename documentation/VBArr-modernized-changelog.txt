---VBA-rr Modernized Edition (v24.1 for the V8 core, v23.7 for the V7 core)---
The Modernized Edition carries the VBA-rr line on from the upstream revision
4526341 (2019-09-15).  The savestate and movie formats, the re-recording
semantics and the emulation timing are unchanged, so every existing recording
still replays exactly the way it did; what changed is the shell around them.
The entries below are in the same style as the older changelogs, which cover
the releases up to v23.5.

10-26-2026 Carter Li - Lua: Run several scripts at once, one window each. The engine kept a single lua_State next to a dozen file-scope statics, so loading a script stopped the previous one, every register*() call replaced the last script's callback, and the console was a singleton window as well. The per-script state is one VbaLuaState object per window now, the frame and hook dispatchers walk the list of live scripts, and File -> Lua Scripting -> New Lua Script Window really opens a new window (dropping a .lua on the main window opens one too). Joypads, the gui canvas and the memory hooks are merged across scripts, and a callback that throws stops only its own script instead of closing the whole engine.
10-26-2026 Carter Li - Lua: Print Chinese out of a script that declares itself UTF-8. The console decoded a script's bytes in the ANSI code page, so a UTF-8 literal came out as garbage. A .lua file saved as UTF-8 with a BOM now has its print output, its error messages and gui.popup() text decoded as UTF-8, and the BOM is dropped before Lua 5.1 sees it - which used to reject such a file outright with "unexpected symbol near '\239'". A file without a BOM is read exactly as before: the bytes cannot tell UTF-8 from the code page, so nothing is guessed.
10-25-2026 Carter Li - Win32: Let a debugger reach the GBA again. The window that waits for gdb asked the listening socket to post a message as soon as one arrived, but nothing in its message map answered that message, so the connection was never accepted and the window sat on "Waiting..." forever - gdb could not connect at all, and the Debug menu had been in that state since the first revision of the file. The message is mapped now: gdb attaches, reads the registers and the stub answers a stop reply.
10-24-2026 Carter Li - Win32: Give the menus their accelerator column back. Every item was rewritten as its caption, a tab, the shortcut and then a tab of its own, and Windows reads what follows the last tab as the accelerator - an empty one - so Windows 11 dropped the column from every entry while the classic menu of Windows 7 drew the leftovers as stray glyphs. Both halves are joined with a single tab now, and an item whose text cannot be read is skipped instead of being written back out of an uninitialised buffer.
10-24-2026 Carter Li - Lua: Say why a script did not start. The console was created only after the file had been read, so a missing or unparsable file was reported into a NULL print sink and went to stderr, which a windowed program has nowhere to put - Run appeared to do nothing at all. The console now exists before the load, so the error names the file and the line. Clicking Run with no game running says so in the console too, instead of ignoring the click.
10-24-2026 Carter Li - Win32: Stop the Lua console from printing garbage. The console is a Unicode edit control and a script's output was handed to it as raw bytes, so every two bytes became one random character and CR LF came out byte swapped - which also meant the output never started a new line; the text now goes through the same ANSI to wide conversion the rest of the frontend uses.
10-24-2026 Carter Li - Win32: Explain a cheat in words. The cheat list now has an Explain button: with one row selected it opens a window that says what each code of that row - or of the whole group - does, which address gets which value, which key has to be held and which condition has to hold, so a pasted code no longer has to be decoded by hand.
10-24-2026 Carter Li - Win32: Translate the Undo/Redo caption of the RAM Search button. It was set from an ANSI literal through WM_SETTEXT on a Unicode button, so the first search left two meaningless characters there instead of the word.
10-24-2026 Carter Li - Win32: Say the RAM Search window title in the UI language. The title is rebuilt with the result counts after every search and the words were hard coded English, so the window fell back to English even though its dialog caption was translated; the two halves now come from the string table, with only the counts going through the format.
10-24-2026 Carter Li - Win32: Add a Memory button to RAM Search and RAM Watch. With a row selected it opens a memory viewer on that address, in the data size the row is searched or watched at, so a value found by the search no longer has to be retyped into the viewer.
10-24-2026 Carter Li - Win32: Keep the line breaks of a pasted cheat code list. The EDIT control only starts a new line on CR LF, so codes copied from a web page with bare LF line endings were stored as is but drawn as one long line; the cheat code boxes now rewrite the clipboard text to CR LF before the control sees it, which covers Ctrl+V and the context menu Paste alike.
